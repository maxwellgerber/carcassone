# Tile geometry contract

Every tile is authored once, in canonical (unrotated) orientation, as a 200×200 SVG.
The client rotates the canonical artwork by `rot * 90deg` at draw time (canvas
transform) to produce all four orientations — art is never drawn per-rotation.

This is why two independently-illustrated tiles still connect at a shared edge:
the elements marked `data-structural="true"` in each tile's base SVG encode the
*exact* city/road/border geometry derived from `src/shared/tiles.ts` (the same
edge/rotation math the game engine uses for legality and scoring). An artist may
restyle a structural element's `fill`/`stroke`/pattern/gradient and may add any
number of new decorative elements on top, but must never change a structural
element's coordinates (`d`, `cx`/`cy`/`r`, `x`/`y`/`width`/`height`). Two tiles
whose city petals or road paths both terminate at the same locked coordinates on
a shared edge will always seam correctly, regardless of interior decoration.

Generated by `scratch-art/generate-base-svgs.ts` from `TILE_TYPES`, one file per
canonical tile key, into `scratch-art/base/*.svg`.
